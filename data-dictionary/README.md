## Instructions

This data dictionary app is customizable app that you can customize using a google sheet. The key benefit of this app is that you can add definitions to your fields, so your stakeholders can become more knowledgeable about key fields in your database and which ones to use for targeting purposes.

Clone this spreadsheet and add the ID to your local environment variables: https://docs.google.com/spreadsheets/d/1nWpKG3esnA9fvQLNzvIp_FTKRL8TRhMlyLXiyKdB1Nc/edit?gid=0#gid=0

The audience builder also enables your users to provide you detailed audience requirements. If you use Inflection, this builder will look familiar. In order to enable saved audiences, you'll need to setup a database (i.e. KV storage, Supabase, or similar).


This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).
